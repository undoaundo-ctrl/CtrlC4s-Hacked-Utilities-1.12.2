# CtrlC4's Hacked Utilities (Minecraft 1.12.2)

Based on TrollHack 1.4.0 by Luna5ama (GPL-3.0). Original licenses and credits apply; source stays public with the jar.

## Install
1. Minecraft 1.12.2 + Forge 14.23.5.2860 (2859 also works)
2. Put the jar from the release in `mods`: `TrollHack-1.4.0-fatjar-optimized.jar`
3. **Baritone is NOT bundled anymore** (the bundled copy broke under MixinBooter). Also put the official Baritone jar in `mods`: baritone-standalone-forge-1.2.19.jar from https://github.com/cabaletta/baritone/releases/tag/v1.2.19
4. Optional: MixinBooter, LoliASM, RenderLib, Nothirium.

Default GUI key is Y, command prefix is `;`.
