# CtrlC4's Hacked Utilities (Minecraft 1.12.2)

Based on TrollHack 1.4.0 by Luna5ama (GPL-3.0), which bundles Baritone (LGPL-3.0, cabaletta). Original licenses and credits apply; source stays public with the jar.

Install: Minecraft 1.12.2 + Forge 14.23.5.2860, drop the jar in `mods`. Default GUI key is Y, command prefix is `;`. If you crash with an IllegalAccessError mentioning baritone, remove `-Xverify:none` / `-noverify` from your JVM arguments.
